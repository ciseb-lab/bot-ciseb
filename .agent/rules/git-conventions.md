# Convenção de Commits Git (Deploy)

Em todos os commits e deploys deste projeto, organize as alterações por propósito lógico utilizando **sempre** uma das nomenclaturas abaixo no prefixo da mensagem de commit:

- **Feat**: Funcionalidades (implementação)
- **Fix**: Conserto
- **Refactor**: Refatoração (Refazer)
- **Docs**: Documentação
- **Style**: Estilização
- **Hotfix**: Implementação, melhoria ou conserto urgente
