# Bot CISEB

Aplicação de apoio pedagógico. O código do app está em `bot-ciseb/`.

## Organização

```text
bot-ciseb/
├── frontend/   # React, Vite, telas, estilos e assets
├── backend/    # Express, Firebase Admin, Gemini e PDFs institucionais
├── shared/     # Política institucional e catálogo curricular compartilhados
├── test/       # Testes automatizados
├── docs/       # Arquitetura, segurança, Firebase e deploy
└── package.json
```

Os comandos de instalação, teste e build são executados na pasta `bot-ciseb/`. Consulte [bot-ciseb/README.md](bot-ciseb/README.md) para desenvolvimento e [bot-ciseb/DEPLOY.md](bot-ciseb/DEPLOY.md) para hospedagem.
